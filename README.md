# STARLINE · 星际防线

纯前端纵版弹幕射击：单文件 HTML，零依赖、零后端、无平台角标。

**在线玩：https://qvq-sgu.github.io/**

## 玩法

- 5 关：1–4 关各 40 秒清场，第 5 关打母舰「黄畧号」直至击毁
- 自动开火，拖动屏幕或 WASD / 方向键移动，ESC / P 暂停
- 判定半径只有 9px；5 格血 + 护盾层，脱战 8 秒回一层护盾
- 过关进改装台，用合金升级主炮 / 护盾 / 引擎 / 僚机
- 本地 Top10 排行榜，只在当前浏览器

## 全设备适配

| 设备 | 处理 |
| --- | --- |
| 桌面 | 双栏：左侧任务线，右侧 470px 机台 |
| 平板横竖屏 | 单栏居中，机台最大 520px，卡片两列 |
| 手机 | 导航收起、数据两列、按钮通栏，开局后机台自动滚进视野 |
| 手机横屏 | 文案与机台并排，少滚动 |
| 手表 / 极窄屏 | 只留机台（开工按钮在画面内），HUD 简化为分数 / 血量 / 暂停 |
| 全机型 | 机台底部「全屏」按钮，战场按 480:720 等比缩放 |

## 配置后台

页面底部「配置后台」或访问 `/#admin`，改站名 / 公告 / 主色 / 难度 / 游戏参数，可改密码、清空排行榜、导出配置。密码以 SHA-256 哈希写进页面，源码里看不到明文。

## 目录

- `index.html` —— 完整站点（HTML + CSS + JS 全内联）
- `.github/workflows/mirror.yml` —— 从已发布的静态站同步 `index.html`，保证仓库与线上一致
